# Задание 3. Основы React — Выбор даты и времени

Страница выбора даты и времени записи в барбершоп **BORODA CLUB** (Шаг 3 из 5), переведённая на React + Vite в компонентном стиле.

## Как запустить

```bash
npm install
npm run dev
```

После запуска откройте адрес, который выведет Vite (обычно `http://localhost:5173`).
