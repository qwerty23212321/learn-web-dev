# Задание 2. JavaScript — Выбор даты и времени

Интерактивная страница выбора даты и времени записи в барбершоп **BORODA CLUB** на нативном JavaScript.

## Возможности

- Динамический рендер календаря на выбранный месяц и год.
- Переключение месяцев кнопками `<` и `>`.
- Блокировка прошедших дней (раньше сегодняшней даты) с визуальным состоянием `disabled`.
- Выбор дня с автоматическим сбросом ранее выбранного времени и обновлением доступных слотов.
- Выбор свободного слота времени; занятые слоты визуально приглушены и заблокированы.
- Динамическое обновление карточки выбранной даты и нижней панели итогов (`День недели, число месяц год • время`).
- Подтверждение выбранных даты и времени по кнопке «Продолжить».

## Как открыть проект

Откройте `index.html` двойным кликом в браузере или через **Live Server** в VS Code.
