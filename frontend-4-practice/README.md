# Задание 4. Асинхронный JavaScript и создание React-приложений

Страница выбора даты и времени записи в барбершоп **BORODA CLUB** (Шаг 3 из 5), подключённая к имитационному API-серверу на базе Vite.

## Как запустить

```bash
npm install
npm run dev
```

После запуска откройте адрес, который выведет Vite (`http://localhost:3000`).

## Эндпоинты имитационного сервера

- `GET /api/booking/today` — возвращает `{ day, month, year }` (`month` 0-индексный).
- `GET /api/slots?day=&month=&year=` — возвращает `{ date, slots }` для выбранного дня.
