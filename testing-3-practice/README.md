# [Тестирование] Задание 3 — Техники тест-дизайна (ÉLAIRE)

## Задание 3.1. Классы эквивалентности и граничные значения

### 1. Поле «Номер телефона»
**Требование:** российский мобильный номер в формате `+7 (ХХХ) ХХХ-ХХ-ХХ` (`11` цифр, начинается с `+7`, код российского мобильного оператора `9XX`).

#### Классы эквивалентности
| Класс | Тип | Описание | Пример |
| --- | --- | --- | --- |
| `КЭ-Т1` | Валидный | Российский мобильный номер из 11 цифр в формате `+7 (ХХХ) ХХХ-ХХ-ХХ` (код `9XX`) | `+7 (999) 123-45-67` |
| `КЭ-Т2` | Невалидный | Пустое поле (обязательное поле не заполнено) | `""` |
| `КЭ-Т3` | Невалидный | Менее 11 цифр (неполный номер) | `+7 (999) 123-45-6` |
| `КЭ-Т4` | Невалидный | Более 11 цифр | `+7 (999) 123-45-678` |
| `КЭ-Т5` | Невалидный | Номер начинается не с `+7` (другой префикс или `8`) | `8 (999) 123-45-67` |
| `КЭ-Т6` | Невалидный | Не мобильный / не российский код оператора (не `9XX`) | `+7 (495) 123-45-67` |
| `КЭ-Т7` | Невалидный | Буквы или недопустимые спецсимволы | `+7 (999) abc-45-67` |
| `КЭ-Т8` | Невалидный | Нарушение формата маски `+7 (ХХХ) ХХХ-ХХ-ХХ` | `+79991234567` |

#### Граничные значения
- **По количеству цифр:** `0` (пусто, невалидно), `10` (`min - 1`, невалидно), `11` (`норма`, валидно), `12` (`max + 1`, невалидно).
- **По коду мобильного оператора (`900–999`):** `899` (невалидно), `900` (валидно), `999` (валидно).

#### Граничные тесты для поля «Номер телефона»
1. **Тест 1 (нижняя граница валидности, 11 цифр, код `900`):**
   - Вводимое значение: `+7 (900) 000-00-00`
   - Ожидаемый результат: номер принят (валиден), ошибка валидации не отображается.
2. **Тест 2 (менее 11 цифр — `10` цифр, `min - 1`):**
   - Вводимое значение: `+7 (999) 123-45-6`
   - Ожидаемый результат: номер отклонён, отображается ошибка валидации (неполный номер).
3. **Тест 3 (более 11 цифр — `12` цифр, `max + 1`):**
   - Вводимое значение: `+7 (999) 123-45-678`
   - Ожидаемый результат: ввод лишней цифры блокируется маской или отображается ошибка формата.
4. **Тест 4 (граница мобильного кода `900 - 1`):**
   - Вводимое значение: `+7 (899) 123-45-67`
   - Ожидаемый результат: номер отклонён как не являющийся российским мобильным номером.

### 2. Поле «Ваше имя»
**Требование:** только буквы кириллицы, длина от `2` до `40` символов включительно.

#### Классы эквивалентности
| Класс | Тип | Описание | Пример |
| --- | --- | --- | --- |
| `КЭ-И1` | Валидный | Только кириллические буквы длиной от 2 до 40 символов | `Анна` |
| `КЭ-И2` | Невалидный | Пустое поле или строка только из пробелов | `""` / `"   "` |
| `КЭ-И3` | Невалидный | Длина меньше 2 символов (1 символ) | `А` |
| `КЭ-И4` | Невалидный | Длина больше 40 символов (41+ символов) | `Аннаалександрамарияекатеринаеленаольгасве` (41 символ) |
| `КЭ-И5` | Невалидный | Латинские буквы | `Anna` |
| `КЭ-И6` | Невалидный | Цифры в имени | `Анна123` |
| `КЭ-И7` | Невалидный | Спецсимволы и знаки препинания | `Анна!@#` |

#### Граничные значения
- **По длине строки:** `0` (невалидно), `1` (`min - 1`, невалидно), `2` (`min`, валидно), `3` (`min + 1`, валидно), `39` (`max - 1`, валидно), `40` (`max`, валидно), `41` (`max + 1`, невалидно).

#### Граничные тесты для поля «Ваше имя»
1. **Тест 1 (нижняя граница `min = 2` символа):**
   - Вводимое значение: `Ян` (2 кириллические буквы)
   - Ожидаемый результат: имя принято (валидно), ошибка не отображается.
2. **Тест 2 (значение ниже минимума `min - 1 = 1` символ):**
   - Вводимое значение: `А` (1 кириллическая буква)
   - Ожидаемый результат: имя отклонено, отображается ошибка валидации (минимум 2 символа).
3. **Тест 3 (верхняя граница `max = 40` символов):**
   - Вводимое значение: `Александраалександраалександраалександра` (40 кириллических букв)
   - Ожидаемый результат: имя принято (валидно), ошибка не отображается.
4. **Тест 4 (значение выше максимума `max + 1 = 41` символ):**
   - Вводимое значение: `Александраалександраалександраалександрра` (41 кириллическая буква)
   - Ожидаемый результат: ввод 41-го символа заблокирован или отображается ошибка валидации (максимум 40 символов).

## Задание 3.2. Таблица решений для шага «Подтверждение записи»

**Правило:** запись подтверждается (`Подтвердить запись`), только если заполнено поле `Ваше имя`, заполнено поле `Номер телефона` И телефон валиден.

Условия:
- **У1:** Поле «Ваше имя» заполнено (`Да` / `Нет`)
- **У2:** Поле «Номер телефона» заполнено (`Да` / `Нет`)
- **У3:** Номер телефона валиден (`Да` / `Нет`)

| Комбинация | П1 | П2 | П3 | П4 | П5 | П6 | П7 (логически невозможна) | П8 (логически невозможна) |
| --- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **У1: Имя заполнено** | Да | Да | Да | Нет | Нет | Нет | Да | Нет |
| **У2: Телефон заполнен** | Да | Да | Нет | Да | Да | Нет | Нет | Нет |
| **У3: Телефон валиден** | Да | Нет | Нет | Да | Нет | Нет | Да* | Да* |
| **Результат: Запись подтверждена** | **Да** | **Нет** | **Нет** | **Нет** | **Нет** | **Нет** | **N/A** | **N/A** |
| **Действие 1: Показать окно «Запись подтверждена»** | Да | Нет | Нет | Нет | Нет | Нет | — | — |
