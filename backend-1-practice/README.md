# Backend — Задание 1

Реализация класса `Appointment` и бизнес-правил записи клиента в [main.py](main.py):

- Класс `Appointment` (также доступен под алиасом `Appoinment`).
- `create_appointment` возвращает объект `Appointment` только при заполнении всех полей и наличии мастера/услуги.
- Проверка рабочего времени салона: с `08:00` до `20:00`.
- Защита от двойной записи на одно и то же время.

## Запуск

```bash
python main.py
```
